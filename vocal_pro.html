Overview

What Is VocalPro?

VocalPro is a modern desktop application with a Flutter frontend and a Python AI backend (FastAPI + Demucs) that leverages the Hybrid Transformer deep learning architecture to separate vocal tracks from background instrumentation. Whether you're a musician looking for acapellas, a content creator needing clean voice tracks, or a researcher analyzing audio, VocalPro delivers studio-quality results with a drag-and-drop interface and real-time progress via WebSocket.

How It Works

The Separation Pipeline

VocalPro processes audio through a sophisticated multi-stage pipeline that combines a powerful deep learning model with intelligent post-processing for the best possible results.

📂 Load File → 🎞️ Extract Audio → 📊 Analyze → 🧠 Demucs AI Model → 🎛️ Post-Processing → 🎚️ Stem Mixer → 💾 Export + MIDI
1

Load & Extract

Drag-and-drop any audio (MP3, WAV, FLAC, OGG) or video file (MP4, MKV, AVI, MOV), or paste a URL. For video files, VocalPro extracts the audio stream as a high-quality WAV using FFmpeg, preserving the original sample rate and channel count. A waveform preview renders automatically so you can see the audio before processing.

2

Audio Analysis

Before separation, VocalPro analyzes the audio to extract musical metadata using librosa. BPM detection uses beat tracking to estimate the tempo. Key detection applies the Krumhansl-Schmuckler algorithm on chroma features to identify the musical key and mode (e.g. "C major", "A minor"). Results are displayed in a badge on the waveform preview.

3

AI Source Separation (Demucs)

The heart of VocalPro — a Hybrid Transformer Demucs model processes the audio in overlapping segments. Using a U-Net architecture with transformer attention, it separates the mixed signal into distinct stems. With the htdemucs_6s model, you get up to 6 stems: vocals, drums, bass, other, piano, and guitar. Multiple shift averaging reduces artifacts for cleaner output.

4

Intelligent Post-Processing

The raw separated vocals go through a powerful refinement pipeline:

  • Vocal Activity Detection (VAD) — Identifies which sections contain singing vs. instrumental-only passages
  • Spectral Noise Reduction — Removes residual music bleed using adaptive spectral gating
  • Multi-Band Denoising — Applies different denoising strengths to low (rumble), mid (vocal range), and high (hiss) frequency bands
  • Noise Profile Extraction — Learns the noise fingerprint from silent sections for targeted removal
  • Adaptive Gate Floor — Dynamically adjusts the silence threshold based on the actual noise floor
  • HPSS SFX Separation — Optionally separates sound effects from background music
5

Ensemble & Karaoke Mode

Ensemble mode runs the audio through multiple Demucs models (htdemucs_ft + mdx_extra) and averages the vocal outputs, blending strengths of different architectures for cleaner results. Karaoke mode sums all non-vocal stems (drums, bass, other, piano, guitar) into a single instrumental track, exported as a _karaoke.wav file alongside the vocals.

6

Stem Mixer & MIDI Extraction

After separation, the Stem Mixer panel (bottom of the GUI) shows individual volume sliders for every stem — 4 sliders for standard models, 6 for htdemucs_6s. Each slider ranges from 0% to 200%, letting you remix stems at custom levels. Click "Mix & Export" to save the custom mix, "📦 Export All (Custom)" to save each stem at its slider level, or "Export All Stems" to save every stem separately. The "🎵 MIDI" button next to any melodic stem extracts its pitch contour, and "🎵 MIDI All" processes all melodic stems at once.

7

Export & Mux

Choose your output format (WAV, MP3, or FLAC) and download. For video files, VocalPro automatically muxes the clean vocals back into the original video with sample-accurate sync. Optionally mix background audio back in, generate comparison samples, or save the full background track separately.

How to Use

Getting Started with VocalPro

Using VocalPro is straightforward. Follow this step-by-step guide to go from launching the app to exporting your first clean vocal track.

1

Launch the App

Double-click run.bat in the project folder. This starts the Python AI server (the backend) in the background and opens the VocalPro desktop window. The first time you run it, it may take a few seconds to initialize. A splash screen shows the connection status — wait until it says "Connected" and the main UI appears.

⚠️ If the app window doesn't appear, install the VC++ Redistributable and try again.

2

Load an Audio or Video File

You have three ways to load files:

  • Drag & Drop — Drag any audio file (MP3, WAV, FLAC, OGG) or video file (MP4, MKV, AVI, MOV) onto the drop zone in the top card.
  • Browse — Click the Browse button to open a file picker dialog. Select one or more files.
  • URL — Paste a URL (e.g. YouTube link) into the URL field and click Download. VocalPro will download and process the audio.

Once loaded, a waveform preview renders automatically. BPM and musical key are detected and displayed in a badge above the waveform.

3

Configure Settings (Optional)

Before processing, you can fine-tune settings in the SETTINGS card:

  • AI Model — Choose from 8 Demucs models. htdemucs_ft is recommended for best quality.
  • Segment / Overlap / Shifts — Controls how the model processes audio. Longer segments give better context but use more memory. More shifts reduce artifacts but take longer.
  • Output Format — WAV (lossless), MP3 (smaller), or FLAC (compressed lossless).
  • Post-Processing — Toggle vocal gate, spectral denoising, multi-band denoising, noise profiling, and adaptive gate floor. Each can be enabled/disabled independently.
  • Karaoke Mode — Enable to export an instrumental track alongside the vocals.
  • Ensemble Mode — Enable to run multiple models and average results for cleaner output.
4

Run Separation

Click the RUN button to start the separation process. VocalPro processes files one at a time if you queued multiple. A progress bar shows the current file's progress, and the log area displays detailed status messages. You can click Cancel to stop at any time.

When complete, the output folder opens automatically. Each separated stem is saved as a separate file.

5

Use the Stem Mixer

After separation, the STEM MIXER card appears at the bottom of the window with individual volume sliders for each stem (vocals, drums, bass, other, and optionally piano + guitar with the 6-stem model).

  • Drag sliders to adjust volume (0% to 200%) for each stem independently.
  • Click 🎧 Mix & Export to save the blended result as a single file.
  • Click 📦 Export All (Custom) to save each stem at its slider level.
  • Click Export All Stems to save every stem at full volume.
  • Click 🎵 MIDI next to any stem to extract pitch contours as a MIDI file.
  • Click 🎵 MIDI All to extract MIDI from all melodic stems at once.
6

Export & Review

All separated files are saved to an output folder named with the original file name and timestamp. The output folder opens automatically after processing. You'll find:

  • Vocals — Clean vocal track (post-processed)
  • Background — Music track without vocals (if enabled)
  • Individual stems — Drums, bass, other (and piano/guitar if using 6-stem model)
  • Comparison samples — 3 random clips of original vs separated for quick A/B testing (if enabled)
  • Karaoke track — Instrumental mix (if karaoke mode was enabled)
  • MIDI files — Raw and smoothed pitch contours (if extracted)

💡 Tips for Best Results

  • Use WAV output format for maximum quality — it's lossless. MP3 is fine for quick tests.
  • Start with the htdemucs_ft model — it's the best all-around choice. Switch to htdemucs_6s if you need separate piano/guitar stems.
  • Increase shifts to 5+ for cleaner vocals (reduces artifacts), or keep at 1 for fastest processing.
  • Enable ensemble mode for the cleanest possible vocals — it runs multiple models and averages results, at the cost of longer processing time.
  • If vocals sound muffled or have too much music bleed, increase denoise_strength or enable multi-band denoising with gentler mid-band settings.
  • Use karaoke mode to create instrumental tracks for practice or covers.
  • For video files, VocalPro automatically muxes clean vocals back into the original video — check the video_output_mode setting to control whether the video-only file is kept.
Features

Everything You Need for Clean Vocal Extraction

From AI model selection to fine-grained audio processing controls, VocalPro puts professional-grade tools at your fingertips.

🎤 Vocal Activity Detection

Combines RMS energy, spectral flatness, and spectral centroid analysis to accurately detect vocal regions. Silences instrumental-only sections while preserving natural attack and decay with smooth raised-cosine fades.

🔊 Spectral Noise Reduction

Uses the noisereduce library with non-stationary mode to adapt to varying music backgrounds. Supports explicit noise profiles extracted from VAD-identified silent sections for targeted removal.

🎛️ Multi-Band Denoising

Splits the signal into low (rumble), mid (vocal range), and high (hiss) bands using zero-phase Butterworth filters. Each band gets its own denoising strength — gentle on vocals, aggressive on noise. Exact reconstruction: low + mid + high = original.

📊 Adaptive Gate Floor

Instead of a static silence threshold, VocalPro measures the actual noise floor from non-vocal sections and adjusts the gate floor dynamically, ensuring optimal silence without cutting into quiet vocal passages.

🔬 HPSS SFX Separation

Uses Harmonic-Percussive Source Separation (librosa HPSS) to decompose the background track into music (harmonic) and sound effects (percussive) components. No separate model needed — fast, mathematically exact.

📁 Batch Processing

Queue multiple files for sequential processing. VocalPro tracks overall progress, reports per-file status, and automatically opens the output folder when done. Includes cooldown between files for thermal management.

🎞️ Video Muxing

Extracts audio from video files, processes it, and muxes the clean vocals back with sample-accurate sync using atrim+apad filter chains. Supports faststart for web-optimized MP4 output.

📋 History & Re-Run

Both download and separation history are persisted to disk with full settings. One-click re-run lets you repeat a previous separation with the exact same configuration.

🎵 Comparison Samples

Automatically extracts 3 random short clips from original and separated audio, saving them side-by-side for instant A/B comparison — great for demoing results.

⚡ GPU Acceleration

Auto-detects CUDA-capable GPUs and tunes segment length based on available VRAM. Supports TF32 matmul precision, cudNN benchmarking, and automatic memory management for optimal throughput.

🎤 Karaoke Mode

When enabled, VocalPro sums all non-vocal stems (drums, bass, other, piano, guitar) into a single instrumental track and saves it alongside the vocals as a _karaoke.wav file. Perfect for sing-along practice or instrumental covers.

🎵 BPM Detection

Analyzes the loaded audio using librosa.beat.beat_track to estimate tempo in beats per minute. Displayed as a badge in the waveform preview area alongside the musical key.

🎹 Musical Key Detection

Estimates the musical key using the Krumhansl-Schmuckler key-finding algorithm. Computes a chroma CQT spectrogram, correlates it against major/minor key profiles, and displays the result (e.g. "C major", "A minor") in the waveform badge.

🎛️ Stem Mixer

After separation, the STEM MIXER card appears with individual volume sliders (0%–200%) for every stem. You can remix stems at custom levels, export the mix, or export all stems as separate WAV files. The mixer dynamically adapts to the number of available stems (4, 6, or 8).

📊 Waveform Preview

A Flutter CustomPainter-based waveform visualization renders the loaded audio as animated amplitude bars with an accent gradient. Shows a playback cursor, supports tap-to-seek drag, and displays real-time elapsed/remaining time.

⌨️ Keyboard Shortcuts

Ctrl+O — browse for files   Ctrl+R — start separation   Esc — cancel current operation. The log area has a dedicated Clear button to reset output.

🎹 6-Stem Model Support

The htdemucs_6s model extends standard 4-stem separation by adding dedicated piano and guitar tracks. The stem mixer automatically displays 6 sliders when this model is used.

📝 MIDI Extraction

Extracts melodic pitch contours from any stem using librosa.pyin (probabilistic YIN). Saves three outputs: a raw MIDI file, a smoothed MIDI file (median-filtered), and a debug WAV of the detected pitches. Accessed via the "🎵 MIDI" button in the Stem Mixer for each stem.

🔀 Ensemble Mode

Runs audio through multiple Demucs models (htdemucs_ft and mdx_extra) and averages the vocal outputs. This blends the strengths of different architectures, producing cleaner vocals at the cost of longer processing time.

Demucs Architecture

Demucs (Demucs: Deep Extractor for Music Sources) uses a Hybrid Transformer architecture that combines the strengths of convolutional U-Nets with transformer attention layers. The model processes the input spectrogram through an encoder-decoder structure with skip connections, applying self-attention at multiple scales to learn the complex patterns that distinguish vocals from instruments. The result is state-of-the-art separation quality that handles diverse music genres, from pop and rock to orchestral and electronic.

Configuration

Fine-Tune Every Aspect

VocalPro exposes a comprehensive set of configuration options through its intuitive GUI — from model selection to advanced audio processing parameters — all persisted to ~/.vocalpro_config.json.

model_name
AI Model Choose from 8 Demucs models. htdemucs_ft is recommended for best quality.
segment
Segment Length 2–60 seconds. Longer = better context for the model, but uses more VRAM. Auto-scaled based on GPU memory.
overlap
Overlap 0–30 seconds. Controls how much adjacent segments overlap. Higher = smoother transitions, slower processing.
shifts
Model Passes (Shifts) 0–20. Random shift averaging reduces artifacts. 1 = fastest, 3+ = best quality, slower.
output_format
Output Format WAV (lossless), MP3 (compressed), or FLAC (compressed lossless).
enable_vocal_gate
Vocal Gate Silences instrumental-only sections. Uses VAD to detect vocal activity and applies smooth gating.
gate_threshold_db
Gate Threshold -80 to 0 dB. Lower = more sensitive vocal detection. Adjust based on how quiet the vocals are.
gate_floor_db
Gate Floor -120 to -20 dB. Silence level when gate is closed. Lower = quieter silence.
enable_spectral_denoise
Spectral Denoising Reduces residual music bleed in vocal segments using spectral gating noise reduction.
denoise_strength
Denoise Strength 0–1. How aggressively to remove noise. Higher = cleaner but may affect vocal quality.
enable_multiband_denoise
Multi-Band Denoising Splits audio into low/mid/high bands with per-band denoising. Mid band gets gentler treatment to preserve vocals.
denoise_strength_*
Per-Band Strengths Low (rumble): 0.90, Mid (vocals): 0.65, High (hiss): 0.80. Configure each band independently.
enable_noise_profile
Noise Profiling Extracts a noise sample from VAD-identified silent sections for targeted spectral denoising.
adaptive_gate_floor
Adaptive Gate Floor Dynamically adjusts gate floor based on actual noise floor measurements for optimal silence.
enable_sfx_separation
SFX Separation Splits background track into music (harmonic) + sound effects (percussive) using HPSS. Saves separate files.
include_sfx
Include SFX in Mix Mixes background audio (or just SFX part if SFX separation is active) back into the vocal output.
save_background_track
Save Background Saves the full background/karaoke track as a separate file.
generate_comparison_samples
Comparison Samples Generates 3 random A/B clips (original vs. processed) for instant quality comparison.
trim_silence
Trim Silence Removes leading and trailing silence from the output file.
karaoke_mode
Karaoke Mode Saves a _karaoke.wav file with all non-vocal stems summed into a single instrumental track. Toggle in OPTIONS section.
ensemble_mode
Ensemble Mode Runs audio through htdemucs_ft + mdx_extra models and averages vocal outputs for cleaner results. Toggle in OPTIONS section.
midi_extraction
MIDI Extraction Extracts pitch contours from melodic stems using librosa.pyin. Saves .mid files (raw + smoothed) and a debug .wav. Triggered per-stem in the Stem Mixer.
stem_mixer_levels
Stem Mixer Levels Per-stem volume sliders (0%–200%) for custom remixing. Automatically adapts to available stems (4, 6, or 8). Mix & Export saves the blended result.
bpm / key
BPM & Key Detection Automatic analysis on file load. BPM via librosa beat tracking, key via Krumhansl-Schmuckler chroma correlation. Displayed in waveform badge.
