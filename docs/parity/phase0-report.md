## 3. Baseline Numbers & Technical Validation Spike Results (`[V]`)

Recorded in `benchmarks/baseline/metrics.json` on the 8-file reference set (`benchmarks/reference-set/`):

### 3.1 Spike (a): Demucs `apply_model` Native Callback & Cooperative Cancel (`[V]`)
- **Finding:** `demucs.apply.apply_model` natively supports `callback: Callable[[dict], None]` and wraps segment futures in `try ... except BaseException: pool.shutdown(wait=True, cancel_futures=True); raise`.
- **Numerical Equivalence:** `max_abs_diff = 0.0` (exact bit-for-bit match against `apply_model(..., callback=None)`).
- **Cooperative Cancel Latency:** `0.063 ms` (`63 µs` to abort inside the segment callback; `< 120 ms` full subprocess round-trip in `test_stdio_worker_subprocess_handshake_and_cancel_under_500ms`, well below the `500 ms` `N5` requirement).

### 3.2 Spike (b): Stdio JSON-Lines Framing & FD Isolation (`[V]`)
- **Finding:** By duplicating file descriptor `1` (`os.dup(1)`) for the JSON-Lines protocol writer and redirecting `os.dup2(2, 1)` + `sys.stdout = sys.stderr` at worker startup (`worker/vocalpro_worker/protocol.py`), even C/C++/PyTorch native writes to `stdout` are routed to `stderr`.
- **Verification:** `test_stdio_worker_subprocess_handshake_and_cancel_under_500ms` and `test_rust_supervisor_and_python_worker_end_to_end` pass with 100% JSON Schema conformance (`schemas/worker-protocol.schema.json`).

### 3.3 Spike (c): Rust Audio Crates (`symphonia`, `rubato`, `hound`, `rusqlite`) & Performance (`[V]`)
- **Waveform Extraction (8,000 peaks on 44.1 kHz stereo WAV):**
  - Legacy Python (`librosa.load` double decode): `1,865.55 ms`
  - Rebuild Rust (`symphonia` single pass): **`< 25 ms`** (**~75x faster**, well under the `300 ms` `ANA-01` target).
- **Stem Mixer Fader Response:**
  - Legacy Python (`POST /stem_preview` disk read + WAV encode + HTTP transfer): `800–2,000 ms`
  - Rebuild Rust (`LiveStemMixer` atomic `f32` gain in `render_interleaved_frames`): **`< 10 ms`** (zero allocations, zero disk I/O).

## 5. Risk Register & Mitigation Summary

| Risk | Severity | Mitigation Implemented |
|---|---|---|
| Third-party Python libraries writing to `stdout` and corrupting JSON-Lines protocol | High | Duplicated original `fd 1` to a private binary stream and redirected `os.dup2(2, 1)` + `sys.stdout = sys.stderr` at process startup (`worker/vocalpro_worker/protocol.py`). |
| Demucs inference blocking `cancel` command | High | Passed native `callback` to `demucs.apply.apply_model` that checks `cancel_event.is_set()` on every segment boundary and raises `JobCancelledError` (`BaseException`), aborting `ThreadPoolExecutor` futures within `< 1 ms`. |
| Legacy config split between `~/.vocalpro_config.json` and `%APPDATA%/VocalPro/` | Medium | Migration checks both `$HOME/.vocalpro_config.json` (and `.vocal_remover_pro_config.json`) AND `%APPDATA%/VocalPro/*.json` (`src-tauri/src/db/migration.rs`). |
| Missing ALSA/WebKit2GTK C headers in headless Linux CI environments | Medium | Separated core Rust library (`vocalpro_lib` with `symphonia`, `rubato`, `hound`, `rusqlite` bundled, `tokio`) from optional `desktop-shell` feature so `cargo test` runs everywhere without system apt packages. |
